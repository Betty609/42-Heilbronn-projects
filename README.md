# 42 Heilbronn projects

A collection of projects I have completed so far as a student at 42 Heilbronn. The repository follows my progress from Linux system administration and C fundamentals to memory management, reusable functions, and sorting algorithms.

## Projects

| Project | What I worked on |
| --- | --- |
| [Born2beroot](core/Born2beroot) | Set up and secured a Debian virtual machine, including users, permissions, SSH, firewall rules, and system monitoring. |
| [Libft](core/libft) | Recreated a selection of standard C library functions and organized them into a reusable library. |
| [Get Next Line](core/get_next_line) | Built a function that reads a file descriptor one line at a time while managing buffers and memory. |
| [ft_printf](core/ft_printf) | Implemented formatted output in C for common character, string, number, pointer, and hexadecimal conversions. |
| [push_swap](core/push_swap) | Designed a C program that sorts integer sequences using two stacks and a limited set of operations. |
| [Piscine C00](piscine/C00) | Practised foundational C exercises, including character and string output. |

Each folder contains the work for a separate 42 assignment. Where available, its README or Makefile has project specific details and build instructions.

These are learning projects, and this repository reflects my progress through the 42 curriculum.
